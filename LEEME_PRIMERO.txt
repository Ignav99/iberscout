# 📦 PAQUETE COMPLETO - IBERSCOUT

## 🎯 ¿Qué es esto?

Este es el **setup completo** para el proyecto IberScout, tu sistema de inteligencia de datos de fútbol. Todo está listo para que lo descomprimas en tu Mac y empieces a trabajar.

---

## 📁 Contenido del Paquete

Este archivo ZIP contiene:

### 📄 Documentación
- **README.md**: Visión general del proyecto
- **INICIO_RAPIDO.md**: Guía para empezar en 5 minutos
- **INSTALACION.md**: Instrucciones paso a paso detalladas
- **PLAN_DE_TRABAJO.md**: Roadmap completo de desarrollo

### 🔧 Scripts de Configuración
- **setup.sh**: Instalación automática (recomendado)
- **verificar_entorno.py**: Verificador completo del entorno
- **docker-compose.yml**: Configuración de PostgreSQL

### ⚙️ Configuración
- **config/settings.py**: Configuración centralizada
- **config/.env.example**: Template de variables de entorno
- **docker/init.sql**: Inicialización de base de datos
- **requirements/research.txt**: Dependencias Python

### 🧪 Scripts de Prueba
- **research/scrapers_test/01_test_scraper.py**: Primer scraper de prueba
- **research/test_db_connection.py**: Test de PostgreSQL

### 🛡️ Otros
- **.gitignore**: Exclusiones para Git
- Este archivo (LEEME_PRIMERO.txt)

## 🚀 Instalación Rápida

### Opción 1: Script Automático (5 minutos)

```bash
# 1. Descomprimir
unzip iberscout_setup.zip
cd iberscout_setup

# 2. Ejecutar instalador
chmod +x setup.sh
./setup.sh

# 3. ¡Listo! Verifica que todo funciona
source .venv/bin/activate
python verificar_entorno.py
```

### Opción 2: Manual

Sigue las instrucciones detalladas en **INSTALACION.md**

## ✅ Pre-requisitos

Antes de ejecutar el instalador, asegúrate de tener:

## 🛠️ Stack Tecnológico

Este proyecto usa:

| Componente | Tecnología | Propósito |
|------------|-----------|-----------|
| **Lenguaje** | Python 3.11+ | Desarrollo principal |
| **Scraping** | Playwright | Navegador automatizado |
| **Parsing** | BeautifulSoup | Extracción de HTML |
| **Datos** | Pandas | Manipulación de datos |
| **Base de Datos** | PostgreSQL 16 | Almacenamiento |
| **Contenedores** | Docker | Aislamiento de servicios |
| **Notebooks** | Jupyter | Experimentación |

## 📖 Filosofía del Proyecto

Este proyecto sigue el principio **"Construir, Comprobar, Guardar"**:

1. **Construir**: Desarrollar incrementalmente (pequeños pasos)
2. **Comprobar**: Validar cada componente antes de avanzar
3. **Guardar**: Versionar y documentar todo

### Arquitectura "Lego"
- Cada componente es independiente
- Se pueden intercambiar sin romper el sistema
- Empezamos simple y evolucionamos

## 🔒 Seguridad y Buenas Prácticas

✅ **Incluido en el setup:**
- Variables de entorno (.env) con passwords aleatorios
- .gitignore configurado para no subir datos sensibles
- Rate limiting en scrapers para "polite scraping"
- Logs estructurados para debugging

⚠️ **Recuerda:**
- Nunca subas el archivo `.env` a GitHub
- Cambia las credenciales de PostgreSQL si vas a producción
- Respeta los robots.txt de las webs que scrapees

## 🆘 Soporte

### Si algo falla durante la instalación:

1. **Revisa los logs**: Cada script muestra mensajes detallados
2. **Consulta INSTALACION.md**: Tiene una sección de "Solución de problemas"
3. **Ejecuta el verificador**: `python verificar_entorno.py`

### Problemas comunes:

- **"Puerto 5432 ocupado"**: Tienes PostgreSQL local corriendo
- **"Docker no responde"**: Reinicia Docker Desktop
- **"ModuleNotFoundError"**: Activa el entorno virtual
